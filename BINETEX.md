# 🤖 Бот-ассистент для онлайн-школы

> Проект для **Binetex** | Python • Aiogram 3 • Redis • Google Sheets

---

## 📌 Описание проекта

Автоматизированный **Telegram-бот** для онлайн-школы, который разгружает менеджеров на **80 процентов**. Бот самостоятельно отвечает на частые вопросы, собирает заявки, передаёт их менеджеру и ведёт полную аналитику.

**Технический стек:** Python 3.12, Aiogram 3, SQLite, Redis, Google Sheets API, Docker Compose

---

## ⚙️ Функционал бота

### 📚 Автоматические ответы
База знаний с поиском по ключевым словам. Поддержка **двух языков**: русский и английский.

### 📝 Система заявок
Автоматический сбор контактов. Бот определяет намерение клиента, создаёт заявку и передаёт менеджеру.

### 🔔 Уведомления в реальном времени
Каждое обращение клиента приходит в специальный чат с **полной информацией** и удобными кнопками управления.

### ✅ Управление статусами
Менеджер управляет заявками **одним нажатием**: принять, перезвонить, отклонить. Ответ клиенту прямо из чата бота.

### 📊 Админ-панель
Воронка конверсии, топ вопросов, расчёт экономии времени, активность пользователей.

### 📖 Управление базой знаний
Добавление, редактирование, удаление вопросов через инлайн кнопки с **пагинацией**.

### 🚫 Система блокировок
Бан, разбан, список блокировок, проверка статуса. Все действия **логируются**.

### 📈 Google Sheets интеграция
Каждая заявка автоматически записывается в таблицу с **форматированием контактов**.

### 📢 Рассылка и защита
Рассылка сообщений всем пользователям. **Rate Limiting** защита от спама.

## 🏗 Архитектура

**Модульная структура** с разделением ответственности. Обработчики, бизнес-логика, сервисы, CRM адаптер, аналитика. **Асинхронная** работа через Aiogram 3 и SQLAlchemy.

**Кэширование** ответов через Redis для мгновенной скорости. Логирование всех действий с ротацией файлов.

**Docker контейнеризация** для быстрого развёртывания.

**Экономия времени.** Менеджер обрабатывает только реальные заявки, а не рутинные вопросы.

**Ни один клиент без ответа.** Бот работает **круглосуточно**, без перерывов и выходных.

**Полная прозрачность.** Статистика и аналитика доступны **в реальном времени**.

**Масштабируемость.** Готовность к росту нагрузки. Поддержка **SQLite и PostgreSQL**.

**Готовность к продакшену.** Проект документирован, покрыт логами, готов к деплою через **Docker**.
