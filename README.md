# 🤖 Бот-менеджер заявок для онлайн-школы

Автоматированный бот для сбора и обработки заявок в онлайн-школу. Разгружает менеджера на 80%, отвечает на частые вопросы через FAQ и ведёт учёт заявок в Google Sheets.

## 📋 Возможности

### Для пользователей:
- ✅ Автоматические ответы на частые вопросы (FAQ)
- ✅ Запись на курс с автоматическим сбором контактов
- ✅ **Inline кнопка отмены заявки** (не нужно писать /cancel)
- ✅ **Редактирование сообщений** при заполнении формы (чистый UI)
- ✅ Поддержка русского и английского языков

### Для менеджера:
- ✅ Уведомления о новых заявках в Telegram-группу
- ✅ Inline-кнопки управления статусами (Принято/Перезвонить/Отказ)
- ✅ Просмотр профиля пользователя с историей
- ✅ Ответ пользователю напрямую из группы
- ✅ Команды: `/leads`, `/lead_info`, `/search`, `/new_leads`, `/callback_leads`

### Для админа:
- ✅ Админ-панель со статистикой (inline + Reply клавиатуры)
- ✅ Воронка конверсии с текстовыми графиками
- ✅ Топ частых вопросов
- ✅ Расчёт экономии времени (в часах и рублях)
- ✅ Управление FAQ через inline-кнопки (добавление/редактирование/удаление)
- ✅ **Управление банами через inline-меню** (бан/разбан/список/проверка статуса)
- ✅ Рассылка сообщений всем пользователям
- ✅ Блокировка/разблокировка пользователей
- ✅ Настройки бота
- ✅ **Все сообщения РЕДАКТИРУЮТСЯ** вместо дублирования (чистый UI)

### CRM:
- ✅ Google Sheets — автоматическая запись заявок
- ✅ **Форматирование номеров** (`7 999 123 45 67` без `#ERROR!`)
- ✅ Автоматическое обновление контактов
- ✅ Синхронизация статусов
- ✅ Адаптер для переключения на локальную БД

### Техническое:
- ✅ Кэширование через Redis
- ✅ Адаптер БД: SQLite / PostgreSQL
- ✅ Логирование с уровнями (DEBUG/INFO/WARNING/ERROR/CRITICAL)
- ✅ Docker Compose для простого развёртывания
- ✅ FSM для многошаговых диалогов
- ✅ Rate Limiting — ограничение частоты сообщений
- ✅ Middleware для inline-кнопок
- ✅ **Полное логирование всех действий админа** (включая ошибки)
- ✅ **edit_message_text** вместо answer для чистого UI

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone <your-repo-url>
cd стартап
```

### 2. Настройка окружения

```bash
# Скопируйте файл конфигурации
cp .env.example .env

# Отредактируйте .env и укажите:
# - BOT_TOKEN (получить у @BotFather)
# - ADMIN_IDS (ваш Telegram ID)
# - MANAGER_CHAT_ID (ID чата менеджера, формат: -100xxxxxxxxxx)
# - GOOGLE_SHEETS_ENABLED=true (для Google Sheets)
```

### 3. Локальный запуск

```bash
# Создание виртуального окружения
python -m venv venv
venv\Scripts\activate  # Windows

# Установка зависимостей
pip install -r requirements.txt

# Запуск бота
python main.py
```

### 4. Запуск через Docker Compose

```bash
# Запуск всех сервисов
docker-compose up -d

# Просмотр логов
docker-compose logs -f bot

# Остановка
docker-compose down
```

## ⚙️ Конфигурация

### Основные настройки (.env)

```env
# Токен бота (обязательно)
BOT_TOKEN=your_telegram_bot_token

# ID администраторов (через запятую, без пробелов)
ADMIN_IDS=123456789,987654321

# ID чата менеджера для уведомлений (формат: -100xxxxxxxxxx)
MANAGER_CHAT_ID=-1001234567890

# Тип базы данных (sqlite или postgresql)
DATABASE_TYPE=sqlite

# Google Sheets
GOOGLE_SHEETS_ENABLED=true
GOOGLE_SHEETS_ID=your_sheet_id
GOOGLE_CREDENTIALS_FILE=./google_credentials.json

# Уровень логирования (DEBUG/INFO/WARNING/ERROR/CRITICAL)
LOG_LEVEL=INFO

# Rate Limiting (сообщений в минуту)
RATE_LIMIT_MESSAGES=5
RATE_LIMIT_LEADS=3
```

### Как получить MANAGER_CHAT_ID:

1. Создай группу в Telegram
2. Добавь бота в группу
3. Сделай бота администратором группы
4. Отправь сообщение в группу
5. Перешли сообщение боту @GetMyID_bot
6. Скопируй ID (формат: `-100xxxxxxxxxx`)

## 📊 Админ-панель

Для доступа к админ-панели отправьте боту команду `/admin`

Доступные функции:
- 📊 Статистика за день/неделю/месяц
- 🔥 Топ частых вопросов
- ⏱ Расчёт сэкономленного времени
- 📝 Управление базой знаний FAQ (inline-кнопки)
- 📤 Экспорт в Google Sheets
- 🔧 CRM настройки
- 🔄 Обновление кэша
- 🚫 **Управление банами** (inline-меню с пошаговой блокировкой)

### Управление банами (inline-меню)

Нажмите **🚫 Управление банами** в админ-панели → откроется меню с кнопками:

| Кнопка | Описание |
|--------|----------|
| ➕ Заблокировать | Пошаговая блокировка (ID → причина → подтверждение) |
| ✅ Разблокировать | Разблокировка по ID с подтверждением |
| 📋 Список блокировок | Показать до 20 последних блокировок |
| 🔍 Проверить статус | Проверить заблокирован ли пользователь |
| ⬅️ Назад | Возврат в главное меню админа |

**Все действия логируются** с деталями (user_id, username, timestamp).

### Управление FAQ (inline-кнопки)

Нажмите **📝 Управление FAQ** в админ-панели → откроется меню с кнопками:

| Кнопка | Описание |
|--------|----------|
| ➕ Добавить вопрос | Пошаговое добавление FAQ (RU → EN → keywords) |
| 📋 Список вопросов | Топ-20 вопросов с пагинацией |
| ✏️ Редактировать | Inline-список FAQ → выбор поля для изменения |
| 🗑 Удалить | Inline-список FAQ → подтверждение удаления |
| ⬅️ Назад в меню | Возврат в главное меню админа |

**Все действия с FAQ логируются** с префиксом `[FAQ]`.

## 🛡 Rate Limiting

Бот ограничивает частоту сообщений для защиты от спама:

- **RATE_LIMIT_MESSAGES** — максимум сообщений в минуту (по умолчанию: 5)
- **RATE_LIMIT_LEADS** — максимум заявок в минуту (по умолчанию: 3)
- Админы освобождены от ограничений
- При превышении — предупреждение + отклонение сообщения
- Счётчики хранятся в Redis (fallback: in-memory)

## 🔄 Миграции БД

Миграции управляются через Alembic. При первом запуске таблицы создаются автоматически.

```bash
# Инициализация Alembic
alembic init alembic

# Создание миграции
alembic revision --autogenerate -m "description"

# Применение миграций
alembic upgrade head
```

## 📝 Логирование

Логи сохраняются в:
- `./logs/bot.log` — основные логи
- `./logs/error.log` — только ошибки

Уровень логирования меняется в `.env`:
```env
LOG_LEVEL=DEBUG  # Для разработки (подробные логи всех действий)
LOG_LEVEL=INFO   # Для продакшена
```

### Что логируется:

**Действия админа:**
- Все нажатия inline кнопок (user_id, username, timestamp)
- Блокировка/разблокировка пользователей (детали + ошибки)
- Изменения FAQ (добавление/редактирование/удаление)
- Экспорт в Google Sheets

**Действия пользователей:**
- Создание заявок (lead_id, контакты)
- Отмена заявок (через inline кнопку)
- Ошибки при обработке сообщений

**Системные логи:**
- Запуск/остановка бота
- Подключение к БД/Redis
- Ошибки API Telegram (с деталями для отладки)

## 🔐 Безопасность

- Не коммитьте файл `.env` в репозиторий
- Используйте сложные пароли для PostgreSQL
- Ограничьте доступ к Redis извне
- Регулярно обновляйте токены бота
- Файл `google_credentials.json` не должен быть в репо

## 🐛 Troubleshooting

| Проблема | Решение |
|----------|---------|
| Бот не отвечает | Проверьте токен в `.env` |
| Нет уведомлений в группе | Убедитесь что бот — администратор группы |
| Redis не подключается | Бот работает без Redis (in-memory cache) |
| Google Sheets ошибка | Проверьте credentials и доступ к таблице |
| MANAGER_CHAT_ID неверный | Формат: `-100xxxxxxxxxx` (с -100 в начале) |
